    Every dot is a possible electron position

    Dots are exact random samples of |ψ|² for the chosen orbital, computed live from the solution of the Schrödinger equation. Dense regions are where a measurement would most likely find the electron.

    Colour is the sign of ψ. It doesn't change the probability, but it matters when orbitals combine.

    Honest caveats. The view auto-zooms, so every orbital looks the same size on screen (real size grows like n²: see Mean radius). The camera rotates, not the atom: an orbital is a stationary state and its cloud never moves. The morph between orbitals is a visual interpolation. The proton is drawn thousands of times too large.

    Units: a₀ = 0.0529 nm (the Bohr radius). z is up.
